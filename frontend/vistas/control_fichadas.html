Control de Fichadas

Elegí el Excel de Asistencia biométrico con Importar Excel de fichadas y revisá las alertas de cada persona. El análisis es solo de consulta: no se guarda nada, así que podés analizar el mismo archivo todas las veces que quieras. Al analizar, lo que debe cada persona se suma solo al banco de horas; cada persona y día se suma una sola vez, así que volver a analizar el mismo archivo no duplica. Los días se cargan en orden: un Excel con fecha anterior al último día cargado en el banco se puede consultar, pero no modifica el banco de horas. Si el día tiene una incidencia cargada (licencia, etc.), no se marca alerta. Los Cód Reg Autoridades Superiores y Externo no se controlan.
